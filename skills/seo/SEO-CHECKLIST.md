# Comprehensive SEO Checklist

## Pre-Launch / Development
- [ ] Staging site is blocked via `robots.txt` or HTTP Auth.
- [ ] No `noindex` tags present on pages intended for indexing before pushing to prod.
- [ ] Architecture follows a logical silo or hub-and-spoke model.
- [ ] Internal links use descriptive anchor text (not "click here").

## Technical SEO
- [ ] Canonical tags are present and accurate on all pages.
- [ ] `robots.txt` does not inadvertently block CSS/JS.
- [ ] XML Sitemap is auto-updating and submitted to GSC.
- [ ] 301 Redirects are mapped for all old/deleted URLs.
- [ ] Site loads under 2.5s (LCP).
- [ ] Mobile viewport is configured correctly.

## Content & On-Page
- [ ] Title tags are optimized, unique, and < 60 characters.
- [ ] Meta descriptions drive CTR and are < 155 characters.
- [ ] H1 tag is unique per page and contains the primary entity/keyword.
- [ ] H2/H3 tags break down the content logically.
- [ ] Images have descriptive file names and ALT text.
- [ ] Content explicitly answers user intent and provides information gain.

## Schema & Structured Data
- [ ] Organization / LocalBusiness schema on Homepage/Contact.
- [ ] Article/NewsArticle schema on blog posts.
- [ ] Product/Review schema on ecommerce pages.
- [ ] FAQPage schema where applicable.
- [ ] Tested via Rich Results Test.

## Off-Page & Authority
- [ ] Social profiles link back to the website.
- [ ] Citations (NAP) are consistent across directories.
- [ ] Backlink profile has been audited for toxic domains.
- [ ] Digital PR campaigns are mapped to core entities.

## Maintenance
- [ ] GSC is checked weekly for crawl errors.
- [ ] Analytics (GA4) conversions are firing correctly.
- [ ] Content decay audit is run quarterly.
