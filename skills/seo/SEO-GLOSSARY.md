# SEO Glossary

- **AEO (Answer Engine Optimization)**: Optimizing content to be chosen as the direct answer in AI overviews, ChatGPT, Perplexity, and voice assistants.
- **Canonical Tag**: An HTML element (`rel="canonical"`) that tells search engines which URL is the master version of a page, preventing duplicate content issues.
- **Core Web Vitals**: A set of specific factors that Google considers important in a webpage's overall user experience (LCP, INP, CLS).
- **Crawl Budget**: The number of URLs search engine bots can and want to crawl on a website within a given timeframe.
- **E-E-A-T**: Experience, Expertise, Authoritativeness, and Trustworthiness. Google's framework for evaluating content quality.
- **Entity**: A distinct, independent thing (person, place, concept, brand) that search engines understand semantically.
- **GEO (Generative Engine Optimization)**: Similar to AEO; focusing on visibility within Generative AI Search models.
- **Information Gain**: The unique value, data, or perspective a piece of content adds to the internet that isn't already covered by existing top-ranking pages.
- **LCP (Largest Contentful Paint)**: A Core Web Vital metric measuring how long it takes for the largest element in the viewport to render.
- **Orphan Page**: A page that has no internal links pointing to it, making it difficult for users and crawlers to find.
- **Topical Authority**: A measure of a website's depth of expertise on a specific subject, achieved by covering the topic comprehensively across multiple interconnected pages.
