# SERP Analysis

## Purpose
To manually or programmatically analyze the Search Engine Results Page (SERP) features to determine search intent and algorithmic preferences for a specific query before creating content.

## What This Skill Does
Prevents the wasted effort of trying to rank a 3,000-word blog post when Google is only showing YouTube videos and eCommerce category pages. 

## Core Concepts
- **SERP Features**: Non-traditional organic results (e.g., Featured Snippets, Local Packs, People Also Ask (PAA), Video Carousels, Knowledge Panels).
- **Zero-Click Searches**: Queries where the user gets the answer directly on the SERP (via a Featured Snippet or Knowledge Panel) and never clicks through to a website.
- **SERP Volatility**: How much the top 10 results fluctuate day-to-day. High volatility implies Google isn't sure what the intent is yet.

## Step-by-Step Workflow
1. **Search the Keyword**: Do this incognito or use a tool to strip personalized search history.
2. **Analyze Intent**: Are the results informational guides? Product pages? Calculators? You MUST match this format.
3. **Check for SERP Features**: 
   - If there is a huge Local Pack, standard organic SEO might yield low traffic.
   - If there is a Video Carousel, you should consider creating a YouTube video instead of an article.
   - Extract the "People Also Ask" questions. You MUST answer these in your content.
4. **Evaluate Difficulty**: Check the Domain Authority (DA) of the top 5 results. If they are all Wikipedia, Amazon, and NYTimes, and you are a new blog, choose a different keyword.

## AI Agent Instructions
IF performing a SERP Analysis:
1. QUERY Google for the target keyword.
2. DETECT the presence of SERP features (Featured Snippet, PAA, Video, Local Pack).
3. CLASSIFY the dominant page type (Blog, E-commerce, Tool, Forum).
4. EXTRACT the text of all PAA questions.
5. RECOMMEND the required content format based on the classification.
